# Замер скорости интернета

Консольный скрипт на Python (только стандартная библиотека, без зависимостей):
делает **10 последовательных** запросов к указанному адресу, дожидается **полного**
ответа каждого и печатает среднее время запроса, общий объём скачанных данных
и скорость скачивания.

## Требования

- Python 3.8+ (проверялось на Python 3.13)
- Доступ в интернет

## Запуск

```bash
python3 speedtest.py <URL>
```

Пример — тяжёлый файл 10 МБ:

```bash
python3 speedtest.py https://proof.ovh.net/files/10Mb.dat
```

Подойдёт любой адрес, который отдаёт тело ответа: картинка, файл, JSON и т.п.

## Пример вывода

```text
# 1:   0.76 c |    10.49 МБ |  109.79 Мбит/с
# 2:   0.72 c |    10.49 МБ |  116.95 Мбит/с
...
#10:   0.72 c |    10.49 МБ |  116.16 Мбит/с
--------------------------------------------------------------
Успешных запросов: 10 из 10
Среднее время запроса: 0.72 c
Общий объём скачанных данных: 104.86 МБ
Скорость скачивания: 116.43 Мбит/с  (14.55 МБ/с)
```

## Единицы измерения

| Единица | Значение |
| --- | --- |
| `c` | секунды |
| `МБ` | мегабайты, **1 МБ = 1 000 000 байт** (десятичная СИ, не 2²⁰) |
| `Мбит/с` | мегабиты в секунду, **1 Мбит = 10⁶ бит** — «провайдерские» единицы (8 бит = 1 байт) |

Формулы:

- **Скорость скачивания** = (все скачанные байты × 8) / суммарное время всех запросов.
- **Среднее время запроса** = сумма времени запросов / количество успешных запросов.
- Итоговая скорость указана сразу в двух единицах: Мбит/с и МБ/с (Мбит/с ÷ 8 = МБ/с).

## Как считает

- Замер на каждый запрос: `time.perf_counter()` до отправки запроса и после чтения
  последнего байта тела — в время попадают подключение (TCP+TLS), ожидание ответа
  и скачивание.
- Запросы строго **последовательные**: следующий стартует только после полного
  чтения предыдущего ответа, интервалы не пересекаются.
- Тело ответа читается **одним вызовом `response.read()` до EOF** — скачивание
  и подсчёт байтов идут внутри C-кода, Python-петля по чанкам убрана
  (замер: 0.39 мс против ~0.000 мс на 10 МБ). Ответ учитывается целиком,
  независимо от заголовка `Content-Length`. Ограничение: тело целиком лежит
  в памяти — для файлов больше ~1 ГБ замените на чтение чанками по 64 КБ.
- Ошибка одного запроса (таймаут, сеть, HTTP-ошибка) печатается в `stderr`
  и не прерывает прогон; итог считается по успешным запросам.
- Редиректы отрабатываются автоматически (urllib следует им по умолчанию).

## Структура

- `speedtest.py` — весь скрипт (~90 строк), без сторонних пакетов.
